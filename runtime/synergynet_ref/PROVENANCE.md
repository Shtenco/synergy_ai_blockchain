# SynergyNet runtime provenance

Imported/adapted for the canonical MVP integration from `Shtenco/synergynet`, branch `feat/static-peer-relay-service-v1-20260821`.

The imported runtime supplies persistent content-addressed storage, bounded TCP content service and static relay behavior. It has **no consensus, payment, accounting or treasury authority**. PQ authentication is provided by the Rust core integration layer and remains a separate acceptance gate.
